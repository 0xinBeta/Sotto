Sotto Privacy Policy

Last updated: July 29, 2026

Local processing

Sotto is a voice assistant for Chrome. Sotto does all inference on your device.

Local inference includes speech recognition, command selection, page tasks, translation, summaries, and optional neural speech.

Sotto does not send your voice, page content, or results to a server.

Network access

Sotto sends network requests only to download fixed model files from Hugging Face.

Each model uses the revision shown below. Sotto caches the files before local inference.

  • onnx-community/moonshine-tiny-ONNX
    Revision: a6da1241cd305dcd64eab1edbd615f2bb9aabb95
  • onnx-community/moonshine-base-ONNX
    Revision: b1e9b6aae3c3c7298f10c3798393fdf38e8fbbad
  • efederici/parakeet-tdt-0.6b-v3-onnx-int4
    Revision: 9828da0021d81df726b3d5ddb2d6d04354942749
  • onnx-community/Kokoro-82M-v1.0-ONNX
    Revision: 1939ad2a8e416c0acfeecc08a694d14ef25f2231

Kokoro voice files use the same repository and revision.

Sotto does not make other network requests.

Local storage

Sotto stores settings, notes, and reminder records in chrome.storage.local.

Settings include speech choices, feature choices, blocked sites, and model state.

Website pages cannot read this extension storage.

You can enable session history. Sotto stores this history in chrome.storage.session.

Session history can contain transcripts, action names, and short result text. Chrome clears it after the browser session.

Sotto stores downloaded models in the browser Cache Storage. You can delete optional models in Sotto.

Audio stays in memory only during the current speech request. Sotto does not keep audio recordings.

Data that Sotto never collects

  • Sotto does not use telemetry or analytics.
  • Sotto does not have accounts.
  • Sotto does not keep audio recordings.
  • Sotto does not transmit page content.
  • Sotto does not sell or share personal data.

Permissions

  • activeTab: Sotto works on the active tab after your command.
  • alarms: Sotto starts local reminder alarms.
  • clipboardWrite: Sotto copies requested text or screenshots.
  • downloads: Sotto saves a file when you request it.
  • notifications: Sotto shows local reminder notifications.
  • offscreen: Sotto uses a hidden extension document for microphone, speech, and local model work.
  • scripting: Sotto reads or changes a page after your command.
  • sessions: Sotto reopens a recently closed tab after your command.
  • sidePanel: Sotto shows its main interface in the Chrome side panel.
  • storage: Sotto keeps local settings, notes, reminders, model state, and optional session history.
  • tabs: Sotto lists, opens, switches, closes, and mutes tabs after your commands.
  • tts: Sotto speaks results with a local system voice.
  • https://huggingface.co/*: Sotto downloads pinned model files from Hugging Face.
  • https://*.huggingface.co/*: Sotto downloads pinned model files from Hugging Face subdomains.
  • https://*.hf.co/*: Sotto downloads pinned model files from the Hugging Face content service.
  • <all_urls>: Sotto requests this optional grant when you start a screen command. Chrome requires this grant to capture the visible tab.
